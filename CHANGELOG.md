# Changelog

## [1.0.0]
- Initial release.
- Added smart heuristic `codeRun` trigger mode.
- Bundled default lightweight success and error WAV sounds.
- Added support for custom WAV sound overrides.
- Safe cross-platform playback via native OS commands (PowerShell, afplay, aplay/paplay).
- Graceful handling of missing shell integration and undefined exit codes.
